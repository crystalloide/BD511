BD511 - Chapitre 8 - Fichiers du handlab « Diagnostic de charge, requêtes lentes et supervision avec Prometheus et Grafana »
Versions : MongoDB 8.3.13, mongosh 2.13.0, Database Tools 100.19.1, percona/mongodb_exporter 0.54.0,
Prometheus 3.15.1 (prom/prometheus:v3.15.1-busybox), Grafana OSS 13.2.4, Docker Engine 29.9.2, Docker Compose v5.6.1,
Python 3.12, Ubuntu 24.04 LTS.

Prérequis : l'instance mongod du chapitre 2 (service systemd, /etc/mongod.conf) et Docker Engine (chapitre 6).

Tous ces fichiers sont aussi générés pas à pas par le handlab (blocs « cat > ... <<'EOF' »).
L'archive sert de secours ou de référence ; leur contenu est identique à celui du handlab.
Aucun secret n'est fourni : les mots de passe sont générés pendant le TP (parties 0.2 et 3.2).

Installation rapide :
  unzip BD511_CH08_fichiers.zip
  mkdir -p ~/BD511
  cp -r BD511_CH08_fichiers/home/BD511/ch08 BD511_CH08_fichiers/home/BD511/supervision ~/BD511/
  sudo install -m 644 BD511_CH08_fichiers/etc/logrotate.d/mongod /etc/logrotate.d/mongod    (partie 2.8 seulement)
  cd ~/BD511/ch08/donnees && gunzip -k ventes.json.gz && sha256sum -c SHA256SUMS
Puis créez les secrets (parties 0.2 et 3.2) : ils ne sont pas dans l'archive.
