BD511 - Chapitre 6 - Fichiers du handlab « Replica set sous Docker : keyFile, élection et write concern »
Versions : MongoDB 8.3.13 (image Docker officielle mongo:8.3.13), mongosh 2.13.0, Database Tools 100.19.1,
Docker Engine 29.9.2, Docker Compose v5.6.1, Ubuntu 24.04 LTS.

Tous ces fichiers sont aussi générés pas à pas par le handlab (blocs « cat > ... <<'EOF' »).
L'archive sert de secours ou de référence ; leur contenu est identique à celui du handlab.

Contenu :
  etc/docker/daemon.json                    réglages du démon Docker : rotation des journaux, live-restore (partie 1.2)
  home/bd511/cluster/architecture.tsv       architecture du cluster, 14 processus (partie 2.1)
  home/bd511/cluster/conf/mongod.conf       configuration commune des mongod (partie 2.5)
  home/bd511/cluster/docker-compose.yml     14 services : RS1 sans profil, RS2/RS3/RSCFG/mongos en profil « sharding » (partie 2.6)
  home/bd511/ch06/00-prerequis.sh           contrôle de la VM (partie 0.3)
  home/bd511/ch06/02-volume-cluster.sh      volume XFS /srv/bd511 et répertoires de données (partie 2.2)
  home/bd511/ch06/03-hosts.sh               noms des membres dans /etc/hosts (partie 2.3)
  home/bd511/ch06/init-rs1.js               initialisation du replica set RS1 (partie 3.2)
  home/bd511/ch06/mongosh-rs1               connexion au replica set, compte admin ou appli (partie 3.4)
  home/bd511/ch06/donnees/                  jeu de données du chapitre 3 + SHA256SUMS (partie 3.5)
  home/bd511/ch06/importer-rs1.sh           import du jeu de données dans RS1 (partie 3.5)
  home/bd511/ch06/surveiller-rs.js          surveillance de l'état des membres (partie 4.1)
  home/bd511/ch06/ecrivain.js               application qui écrit en continu (partie 4.1)
  home/bd511/ch06/attendre-primaire.sh      attente de l'élection d'un primaire (partie 4.4)
  home/bd511/ch06/tester-wc.js              tests des write concerns (partie 5.2)
  home/bd511/ch06/verifier-ch06.sh          contrôle final (partie 6.1)

Non fournis, volontairement : le fichier de clé (secrets/keyfile) et les mots de passe (secrets/*.pwd).
Ils sont propres à chaque installation et se génèrent en partie 2.4 du handlab.

Installation rapide (fichiers du TP, avant la partie 2) :
  unzip BD511_CH06_fichiers.zip
  mkdir -p ~/bd511
  cp -r BD511_CH06_fichiers/home/bd511/ch06 BD511_CH06_fichiers/home/bd511/cluster ~/bd511/
  chmod +x ~/bd511/ch06/mongosh-rs1
  sudo install -m 644 BD511_CH06_fichiers/etc/docker/daemon.json /etc/docker/daemon.json   # après l'installation de Docker (partie 1.1)
